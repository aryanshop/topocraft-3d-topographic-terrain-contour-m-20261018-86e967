# TopoCraft: 3D Topographic Terrain & Contour Map Generator

TopoCraft is an advanced procedural cartography and elevation studio that runs entirely in the browser using HTML5 Canvas and vanilla JavaScript.

## Features

- **Procedural Heightmap Generator**: Layered value-noise algorithms with customizable seeds, feature scale, roughness octaves, and tectonic uplift.
- **Dynamic 2D Contour Maps**: Real-time rendering of elevation bands and precise topographic contour intervals with multiple curated color palettes (Classic Topo, Emerald Isles, Desert Mesa, Monochrome Blueprint, and Neon Cyber).
- **3D Isometric Elevation Model**: Simulated wireframe relief view visualizing topographical peaks and valleys.
- **Region Analytics & Cross-Section Profile**: Instant calculation of max/min elevations, landmass ratios, estimated mountain peaks, and a West-to-East elevation profile graph.
- **Interactive Inspection**: Click anywhere on the 2D map to inspect exact coordinates and elevation values.
- **Export Utility**: Download generated topographic maps instantly as high-resolution PNGs.

## Local Run Instructions

1. Download or clone the repository files (`index.html`, `style.css`, `script.js`, `README.md`).
2. Open `index.html` directly in any modern web browser.

## Technical Note

This is a 100% static client-side application. No external dependencies, frameworks, build tools, or network requests are used.
